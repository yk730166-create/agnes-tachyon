02 // INTERACTIONS

Voice, vision, and interaction.

Core controls stay close through the talk key and notification-area menu.

Fast voice conversations

Hold your chosen talk button, speak naturally, then release. Agnes transcribes the audio, answers with her AI personality, and speaks through Fish Audio S2.1 Pro Free. Choose Agnes - Normal or the deeper Agnes - Adult performance in Options → Voice. Add your own Fish key once; Windows Credential Manager protects it. There is no paid speech fallback or separate local conversion engine.

  • Fast Whisper transcription
  • One consistent Fish Agnes voice
  • Cancelable speech playback
  • Exact physical-key bindings

Play with desktop Agnes

The installed app includes the real Agnes desktop model from this setup, with her complete movement, action, emote and sound bundle. Click, double-click, scroll, or drag her. Right-click her or the tray icon to offer a snack, surprise her with a poke, or start one of the two original Uma music dances. Each dance stops when its music ends. The Agnes above is the guide's smooth in-place preview, paced to look natural instead of rushed.

Live screen awareness

When enabled, Agnes watches the active display locally at up to 10 FPS, keeps useful visual changes, and spends a picture-model request only on a selected keyframe or a direct question about the screen.

Current answers

New hardware, releases, prices, and other changing facts can use live web research instead of relying on old built-in knowledge.

One Agnes only

Starting Agnes again does not create a duplicate. It smoothly brings the existing Options window back instead.

Verified update prompts

Agnes checks the owner-signed release channel when the app opens. Select Download update once to see live progress and verification. An existing copy then updates in place: fresh-setup pages are skipped, app files are replaced in the same folder, settings and protected keys stay safe, and Agnes restarts automatically when it finishes. A signed required update remains active without a connection and pauses live companion services until you update or exit.

03 // PRIVACY CONTROL

You decide what she sees.

Live screen awareness is optional. Local frames stay in a short in-memory buffer; only selected keyframes are sent to the configured AI provider. The Screen & Pet credit guard limits automatic reviews, while a direct question such as “what's that?” captures one fresh frame. Turn it off any time in Options.

  • This guide contains no tracking, analytics, remote fonts, or hidden web requests.
  • No Windows account name, developer folder, or installation directory is printed here.
  • API keys are protected by Windows Credential Manager and hidden in the interface.
  • Use the tray's About and diagnostics panel to find logs on the current computer without exposing that location in this guide.

APPAgnes will not open

Try this first: wait once while the one-file app unpacks, check the notification area, then start Agnes again. If nothing appears, check Windows Security for a blocked or quarantined file and confirm the computer meets the requirements shown here.

APPAgnes disappeared after I closed Options

She is probably still in the notification area near the clock. Select the small overflow arrow if needed, then select Agnes to reopen Options. Closing Options keeps Agnes alive; Quit Agnes exits her.

VOICEThe talk key does nothing

Make sure Agnes—not only Options—is running in the tray. Capture the key again, select Save & close, and try an ordinary unused key. Some games, administrator-only apps, anti-cheat tools, Fn keys, and macro keys can block global key presses.

VOICEMy numpad key is wrong

Capture the key again with Num Lock in its normal state. Most numpad keys—especially Numpad +—should keep their own name. If Enter, Ctrl, or another similar pair still triggers together, choose a more distinct key.

VOICEAgnes cannot hear my microphone

Choose default as the microphone first. In Windows microphone privacy settings, allow desktop apps to use it. Reconnect the microphone, close apps using exclusive audio mode, restart Agnes, and hold the talk key until you finish speaking.

VOICEThe microphone name appears twice or fails to start

Windows can list the same device through several audio systems. Choose default instead of the repeated name, restart Agnes, and test again. This is also the safest choice after plugging a USB headset into a different port.

VOICEI talk, but nothing happens

Try this first: hold the key, say a full sentence, then release it. Speech-to-text always needs a valid Groq key, even when a different company or a local model handles chat. Raise the Windows input level and choose the correct microphone. If the log says Silence ignored, Agnes heard almost no sound.

VOICEThe words are inaccurate or the language is wrong

Select the language you actually speak. Use the recommended Turbo model for speed or the most accurate Whisper option for difficult audio. Move closer to the microphone and reduce fan, keyboard, or room noise.

VOICEI see an answer but hear no voice

Try this first: select default as the speaker and restart Agnes. Then check mute, the Windows volume mixer, Bluetooth, and the normal Windows output. A device can appear in Options but still be unavailable to the playback system, so default is the safest choice.

VOICEThe Fish voice service failed

Exact Agnes speech uses Fish Audio and an internet connection. Open Options → Voice, create a Fish API key, paste it, then Save. Agnes deliberately does not swap to a different Windows or Groq voice when Fish is unavailable. Check the Fish key, Fish balance, connection, and Windows speaker.

AIThe secret key is missing or rejected

Choose the correct AI company in Options, create a fresh key from that company, paste it, save, and fully restart Agnes. A 401 or authentication message means the key is invalid, revoked, or belongs to a different provider.

AIA new key still acts like the old one

Try this first: fully quit Agnes, not only Options, then reopen her. If the old key remains, remove the old GROQ_API_KEY, OPENAI_API_KEY, or GEMINI_API_KEY from Windows environment variables. If you don't know or are not experienced with computers, ask a professional. Never paste a key into the normal settings file.

AIAgnes says “rate limit” or error 429

Stop retrying for a little while, then check the provider quota. Use Fastest or Balanced mode and make screen checks less frequent. Repeated clicks create more requests and make the wait longer.

AIThe AI cannot connect or times out

Check the internet connection and Windows clock. Allow Agnes to use secure web connections through the firewall or school/work proxy, then retry. Do not turn off certificate checking.

AIThe provider and model do not match

Open Advanced settings and clear any custom Base URL, AI model, and Vision model. Switch to a different AI company, then switch back to the company you want so its matching defaults load. Save and restart. For Ollama or LM Studio, start its server and copy the exact model name it shows.

AIAn answer seems old or uncertain

Ask Agnes to verify it live. Live verification currently needs Groq selected as the AI company, plus a working Groq key, connection, and quota. If that is unavailable, check a trusted current source. Agnes should say when a new fact could not be checked.

SCREENScreen reactions are not working

Turn on Let Agnes see my active screen, select a picture-capable vision model, focus the app you want her to watch, and wait one check interval. Unchanged screens are skipped on purpose.

SCREENAgnes watches the wrong monitor

She follows the monitor containing the active foreground window. Select the game or app on the monitor you want, then wait for the next sample.

SCREENThe captured game or video is black

Try borderless or windowed mode and test with a normal desktop window. Protected video, secure Windows screens, anti-cheat systems, and some exclusive-fullscreen games intentionally block screen capture.

SCREENScreen awareness uses too much data or feels slow

Increase the check interval to 5–10 seconds or turn screen awareness off. Chat and voice still work without it. A 1–2 second interval catches more brief events but makes more paid requests.

APPDesktop Agnes will not react

Music dances return to idle automatically when their track ends. If the desktop companion still will not react, confirm Agnes is running in the tray, choose Quit Agnes, and start her once. The animated sprite on this page is a separate guide control. For a locally supplied external pet, also keep its keyboard controls enabled so Agnes can perform the automatic idle reset.

APPEverything feels slow, jumpy, or too large

Set this guide's VFX control to Calm or Off. In Agnes Options, use Fastest or Balanced, turn animations off, use a 3–5 second screen interval, and keep the process-priority boost off while gaming. Restore Windows display scaling to its recommended value.

INSTALLWindows shows a security warning

The current community build is not code-signed. Continue only when the installer came from the expected release and its SHA-256 hash matches the published value. Do not disable Windows Security.

INSTALLReinstalling did not reset broken settings

Normal updates keep your settings. The required 6.6.2 stability update performs one clearly announced reset to remove conflicting old fullscreen and response settings, while keeping protected AI and Fish Audio keys. For a later manual reset, fully quit Agnes, open the installed Agnes folder, open Data, and rename config.toml to config.backup.toml. Reinstall, then review your choices again. Keep the backup until everything works.

UPDATENo update prompt appears

Agnes only shows releases newer than the installed version and only accepts notices signed by the owner key built into the app. Use Check for updates in the notification-area menu. If the channel cannot be reached, check the connection, firewall, Windows clock, and GitHub access, then try again. Agnes 6.2.1 and newer use certificates Windows already trusts. If 6.2.0 reports a certificate-verification error before it can download this fix, install 6.2.1 once from the official release page in your browser. Future checks will then use the Windows trust store. Never disable certificate checking.

UPDATEA required update will not download

Keep Agnes open, free enough disk space, and select Try again. The in-app progress panel downloads and verifies the installer automatically. Agnes rejects incomplete files and anything whose byte size or SHA-256 does not match the signed notice. The verified installer updates an existing copy in place, skips fresh-setup pages, and preserves settings. If it still fails, exit Agnes and download AgnesTachyonSetup.exe from the exact release page shown by the owner.

UPDATEThe same update prompt keeps returning

Let the in-place update finish instead of closing it after the download, then wait while it restarts Agnes automatically. Open About and diagnostics and confirm the displayed version changed. If Windows blocked the installer, use the security-warning steps above without disabling protection.

HELPWhere can I find the error details?

Right-click the tray icon and open About and diagnostics. It shows the log location for this computer without printing it in this guide. Share only the last useful AI, voice, screen, or startup error line—never share the secret key.
